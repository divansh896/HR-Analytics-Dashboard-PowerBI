# HR Analytics Dashboard (Power BI)

# Overview
Built an interactive HR Analytics Dashboard in Power BI to analyze employee attrition, workforce demographics, and departmental performance. The dashboard helps HR professionals monitor employee trends and support strategic workforce planning.

---

# Business Problem
Organizations require HR dashboards to understand employee attrition, workforce distribution, and department-wise employee statistics for better talent management and decision-making.

---

# Objectives
- Monitor employee attrition.
- Analyze workforce demographics.
- Compare department-wise employee distribution.
- Identify employee trends across age groups and education levels.
- Build an interactive HR dashboard.

---

# Dataset
- HR Employee Dataset
- Cleaned and transformed before visualization

---

# Tools Used
- Microsoft Power BI
- DAX
- Microsoft Excel
- Power Query

---

# Dashboard Features
- Employee Count KPI
- Attrition Rate KPI
- Average Age KPI
- Average Salary KPI
- Department Analysis
- Education Analysis
- Gender Distribution
- Interactive Slicers

---

# Key Insights
- Identified departments with higher attrition.
- Compared employee distribution across departments.
- Analyzed workforce demographics.
- Visualized education and gender trends.
